# 快速开始

## 1. 安装与启动

先安装 Git、Python 3.12+、Node.js 22.18+ 和 pnpm，在 PowerShell 中执行：

```powershell
git clone https://github.com/WhiteCai2022/paper-reader.git
cd paper-reader
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\launch.ps1
```

安装脚本会下载 Python / Node 依赖并构建前端。之后双击 `启动阅读器.cmd` 即可；停止时双击 `停止阅读器.cmd`。默认地址为 `http://127.0.0.1:8765`，若端口被占用，启动器会选择后续可用端口并显示实际地址。

如果安装脚本找不到解释器，可显式传入路径：

```powershell
.\setup.ps1 -Python "C:\Python312\python.exe" -Pnpm "C:\tools\pnpm.cmd"
```

路径应替换为本机真实安装位置。源码不包含依赖、论文、个人数据或 API Key，首次运行是空库。

## 2. 导入与阅读

1. 点击“导入 PDF”，选择未加密、可正常解析的 PDF（最大 100 MB）。
2. 核对自动识别的标题、作者、出版信息、年份与 DOI；选择已有分类或新建分类。
3. 导入后，右侧显示原文，左侧可以新增解析，或导入 JSON / Markdown 解读文件。
4. 点击解析条目可跳到对应 PDF 文件页码。公式使用 LaTeX，阅读位置和完成状态自动保存。
5. 左栏按“类别”筛选导读、概念、方法、实验、评读或笔记，也可按核验状态筛选。完成标记表示已读，不代表内容已核验。

分类可以多选；从分类移除条目不会删除文献。删除文献或解析会移入“数据与恢复 → 回收站”，可恢复；PDF、笔记、译文和 API 历史保留，不会立即释放磁盘空间。

## 3. 生成解析

不使用付费 API：点击“精读任务 → 助手任务”，填写阅读重点，把生成的任务交给阅读助手。助手产出解析后，通过“导入解析”追加。文件格式可参考 `examples/` 和 [精读标准](精读标准.md)。

使用 DeepSeek：在右上角设置中验证并绑定自己的 API Key，再选择“精读任务 → API 精读”。选择模型、推理强度和预算，核对估算后确认调用。完成后先预览，再点击“追加到解析 → 确认追加”。不会自动覆盖人工笔记。

默认 Flash、关闭推理，以控制费用。高推理会增加输出预留及费用上限。API 草稿只依据提取文本，图表、复杂公式与结论仍需人工对照原文；格式校验通过不等于学术内容已核验。

新任务默认“学习式全文精读”：全文初读与学习路线、前置知识与概念算例、逐步推导与算法演示、实验设计与结果解读、整篇学习总结与补充评析。先讲直觉，再演算和走算法，减少重复定义与审稿式批评；教学构造会明确标注，不含自测。每阶段都读取全文，无原创实验/算法时按文献实际结构分析。模型选原文片段编号，程序回填原句和页码；未知编号不当作证据，相关正文保留并提示待复核。图表未读到不等于论文没给数据，内容仍须人工核对。补充评析默认折叠，可展开、按类别筛选或从目录定位。旧任务继续原规则，生成新草稿才使用新风格，不自动改写现有解析或收费重生成。费用以新估算为准，不保证比旧版低。

失败、停止或重启中断后，打开原任务，点击“继续未完成阶段”，先免费估算，再确认本次剩余阶段的费用。可在续读确认区调整未完成阶段的输出上限，修改后需更新估算。程序复用已完成阶段及有效草稿，沿用原模型、推理强度与提示；此前费用不会撤销，不确定用量仍保守记账。若要换模型、推理强度或改用新的生成流程，选择“生成新草稿”，它会按整篇新任务计费。没有任何收费自动重试。

解析可附原文证据：在编辑器填写 PDF 文件页码、10–2000 字符的原句和可选标签，再本地检查或定位。匹配成功只说明原句可找到，不说明解析结论正确。人工对照后可设置“已核验”；API 输出始终是“未核验”，修改已核验的正文、页码或证据后须重新复核。

旧版分段任务的引文校验兼容连字、换行断词和中文排版空白；错页只在本条范围内唯一匹配时校正。已有完整返回因证据定位报错时，可先点击“本地重新校验证据（免费）”，通过后恢复该阶段，不重付模型费用；不存在或改写过的引文仍拒绝。继续旧任务仍按原分段流程，切换全文主题流程须选择“生成新草稿”并重新确认费用，旧任务不会被覆盖或自动重跑。

## 4. 翻译与费用

原文批注不收费：选中 PDF 文字，点击选区旁“批注”并保存；左侧“批注”页签提供定位、编辑和删除。批注随文献库 ZIP 备份恢复，不写入原 PDF；删除单条批注确认后无法撤销。

左侧切换到“译文”，选择当前页、范围或全文，确认费用后翻译。已缓存内容可以免费重看；悬停或聚焦译文段落可定位对应原文。“重新翻译当前页”会忽略当前配置的缓存，必须重新确认费用。

首次与重新翻译的新结果都须包含完整、同序、非空的原文段落锚点，不完整结果不会缓存为成功译文。原有旧版缓存继续保留并兼容读取，不自动重译。

上传、浏览、编辑和费用估算不调用收费模型；确认生成后，论文提取文本会发送给 DeepSeek。账户余额来自官方接口，本程序累计预算只约束本工具的支出。停止任务只阻止后续请求，进行中的请求仍可能计费。失败不自动重试。

## 5. 保存与恢复

编辑时未提交的修改暂存于当前浏览器的 `localStorage`，重新打开编辑器可恢复。它不随浏览器迁移，不包含在服务器 ZIP 备份中，也不能代替点击保存；清理浏览器数据或存储失败可能丢失这份临时草稿。

已保存内容有“版本历史”，可预览并确认恢复旧版，较新的已保存历史仍保留。删除、替换导入的旧解析在回收站可找回；恢复解析前须先恢复所属文献。

回收站不会自动过期。手动点击“清空回收站”后，先核对数量，再勾选确认并点击“永久清空”；这会永久删除回收站记录及其关联资料，无法从回收站还原。仅清理程序管理且未被其他文献引用的上传 PDF，不删外部原文、正常文献、费用账本、API Key 或已有备份。文件因占用等原因未能删除时会提示。清空前需要备份请先下载，程序不会额外自动备份或自动重试清空。

右上角“数据与恢复 → 备份与恢复”可以下载文献库 ZIP。备份包含 PDF、解析、版本、回收站、分类、阅读进度、译文及数据库快照；未追加的有效精读草稿另存于 `drafts/*.json`，按对应论文手动导入。浏览器临时草稿和 API Key 不在备份中。

恢复时先校验 ZIP、核对预览，再确认合并。程序先备份当前库，恢复为新的文献和解析 ID，可能产生同名副本，不覆盖现有记录、Key 或费用账本；历史 API 任务只存档，不自动恢复运行。缺失的 PDF 会提示，不能凭备份中的外部路径自动读取本机文件。正在执行 API 任务时不能备份或恢复。

## 6. 常见问题

- 预算不足：降低输出上限或推理强度，或核对单次预算和设置中的累计预算。默认单次金额仍为 2 元，程序不会擅自提高金额预算。
- 输出截断：点击“继续未完成阶段”，在确认区调高“续读每阶段输出上限”，点击“更新续读估算”并确认费用。只重跑未完成阶段，已完成草稿不重复生成。可选整数范围 4096–393216 token；新任务默认关闭/低推理 64K、高推理 128K、最高推理 256K，包含启用时的推理 token。提高上限不保证用完，也不能保证任意输出均不会截断。
- 格式错误：查看失败阶段及具体原因，可下载未通过的最终正文排查，已有有效草稿可导出；修复问题后可估算确认续读。旧版没有保存的响应无法恢复，程序不会猜着修复公式。
- 证据或分类提示：全文主题任务不因额外证据字段、单条错误引用或合法类别偏差而丢弃整阶段。可兼容格式在本地规范化；不能可靠定位的引用移除，相关正文保留并标为“待复核”，任务页可展开检查提示。以前因此停下的完整返回可点击“本地检查并恢复草稿（免费）”，恢复后仅剩余阶段需另行确认 API 费用。检查提示不代表正文已获证据支持或人工核验。
- 扫描 PDF：先 OCR。当前不提供自动 OCR，缺乏可提取文字时不会派发 API 精读。
- PDF 高亮不准：复杂分栏、公式、图表或扫描件可能无法可靠匹配，不会伪造精确定位。
- 直接搬迁原安装：先停止服务，再整体备份 `data/` 及仍被引用的外部 PDF。单篇解析导出不包含 PDF、版本历史或任务账本，GitHub 仓库也不包含文献库。
- 更换电脑或 Windows 用户：重新绑定 API Key，不能依赖原用户的 DPAPI 加密配置。

完整 API 和更多选项见 [README](../README.md)，运行后的交互文档位于 `/api/docs`。
