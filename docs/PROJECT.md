# 项目说明

## 定位与技术栈

论文伴读是本机运行的论文阅读与解析工具，不是公开托管的多人知识库。前端为 React / TypeScript / Vite，PDF 渲染使用 PDF.js，Markdown 与公式使用 react-markdown / KaTeX；后端为 FastAPI / Pydantic，数据保存在 SQLite，文字及版面坐标由 pypdf 提取。

## 目录

```text
backend/                  FastAPI 服务、数据模型、文献管理、翻译与精读任务
backend/tests/            隔离数据与模拟提供方的后端测试
frontend/src/             React 阅读界面与 PDF 段落定位
frontend/tests/           原文匹配、字符偏移与编辑草稿测试
frontend/scripts/         构建时准备 PDF.js / API 文档静态资源
docs/                     快速开始、精读标准与项目说明
examples/                 解析导入模板与翻译接口示例
scripts/                  可选的个人资料迁移及历史测试工具
setup.ps1                 安装依赖并构建前端
launch.ps1 / stop.ps1      Windows 本机服务启动和停止
data/                     运行时数据，自动创建，不上传 GitHub
tmp/                      临时文件与本机验证产物，不上传 GitHub
```

`data/seed.json` 是可选的本机初始化资料，不是源码依赖。正常的新安装没有种子文件，直接从空文献库开始。历史迁移脚本不是默认安装或测试流程。

## 接口与任务

运行后访问 `/api/docs`，OpenAPI 定义位于 `/api/openapi.json`。文献、分类、元信息、笔记、阅读进度和解析导入导出均提供 REST API。

收费任务遵循“本地估算 → 冻结模型/推理/文本/提示策略 → 确认预算 → 后台执行 → 记录用量”。翻译和精读共用 Key、串行执行器、预算控制与账本。失败不自动重试；缺少可核验用量时采用请求预留上限保守记账，需对照官方账单。

精读按“全文初读与阅读地图 → 分类深读 → 整篇总结与证据审查”生成草稿。初读与最终综合均读取全文；深读按概念、方法、实验与评读分条，最终综合使用覆盖所有此前笔记的有界摘要，不截取前几条代替整篇复核。完成草稿内最终总结排在前面，再按类别组织；只有用户确认追加后才写入解析，不改写原人工笔记。

失败、停止或中断的任务可通过 `/api/reading/jobs/{id}/resume/estimate` 免费估算剩余阶段，再以 `quote_id`、`max_cost_cny` 调用 `/resume` 确认续读。沿用原任务 ID、冻结的计划、模型、推理强度与输出限额，保留此前有效草稿和全部用量凭证，仅重新派发未完成阶段。旧任务不会在续读时悄悄升级提示策略；原文或 Key 改变时拒绝沿用旧估算。此前已计费用不会退回，旧的不确定用量凭证保留，新尝试另行记账。生成新草稿仍是完整新任务，不自动复用旧阶段。

JSON 字符串中的原始换行可兼容读取，仍校验结构、页码、每条最低 200 字符与类型。疑似损坏的 LaTeX 控制字符会拒绝，不自动猜测修复。证据保存为 `evidence:[{page,quote,label}]`，API 生成的摘录须在对应提取文本中匹配，生成笔记强制 `verification_status="unverified"`。本地证据接口只检查文字存在性，不判断逻辑支持或学术正确性；界面提供类别与核验状态筛选。不能确定的公式和图表必须人工对照，不能把草稿误称为完整复现或视觉审查。

首次和重新翻译的新结果统一检查原文段落锚点是否完整、同序、非空，失败仍记用量而不写入成功缓存；已有无锚点或第一版锚点缓存的读取与定位保持兼容，不自动重译。

## 数据保护

- 未提交编辑暂存于当前浏览器的 `localStorage`，恢复时检查基线冲突；这是临时草稿，不是数据库保存或备份，也不进入文献库 ZIP。
- 已保存解析的编辑、删除和替换导入保留 `note_versions`，升级时为现存笔记建立基线；无法重建升级前已经丢失的版本。
- 文献与解析以 `deleted_at` 软删除，PDF、分类、译文、草稿和 API 历史保留；恢复文献后才能恢复其解析。回收站不释放磁盘空间，也不自动重放任务。
- 回收站提供手动永久清空：5 分钟预览绑定删除范围与文件状态，二次明确确认；变化后须重览。事务删除回收站记录及关联正文，保留任务和费用账本；只清理 `uploads` 内独占托管 PDF，外部、共享文件和已有备份保留。文件删除失败单独警告；不自动清空、重试或创建新的备份，运行中 API 任务会阻止清空。
- 受管理 PDF 使用相对于 `data/` 的路径，外部种子原文仍依赖外部路径。
- ZIP 备份包含文献、PDF、版本、回收站、分类、进度、译文、一致性数据库快照及未导入有效精读草稿文件，不含 API Key 或浏览器临时草稿。
- 恢复执行路径、文件类型、摘要、PDF 与字段校验，先预览再明确确认，恢复前备份当前库；事务合并为新文献和笔记 ID，不覆盖现有记录。历史任务和账本留在备份数据库中存档，不合并到当前费用账本、不自动运行；未追加草稿的 `drafts/*.json` 需按对应论文手动导入。缺失原 PDF 会明确提示，不把不可信外部路径注册为文件。
- API 任务活动期间禁止备份与恢复。旧 Key 配置不导出、不恢复；搬迁到另一 Windows 用户或机器后重新绑定。

## 开发与测试

完成 `setup.ps1` 后，在项目根目录安装测试依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest backend/tests
```

前端：

```powershell
cd frontend
pnpm test
pnpm build
pnpm dev
```

前端开发服务器将 `/api` 代理到本机 `8765`。可以在另一终端运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

常规测试使用临时数据库及假 API Key，不产生付费模型请求。实际付费测试应单独授权、限定预算并写入账本，不应加入自动测试或 CI。可以通过 `PAPER_READER_DATA_DIR` 指定另一套独立数据目录。

## 安全边界与限制

- 服务仅供本机使用，没有多人认证和权限隔离，不要直接绑定公网地址。
- 仓库只保存源码、文档与模板，不保存论文、个人笔记、缓存、账本、密钥或本机测试输出。
- Windows 界面绑定的 Key 使用当前用户 DPAPI 加密；未绑定时可在后端通过 `DEEPSEEK_API_KEY` 环境变量配置。不要在源码中硬编码密钥。
- DeepSeek 会接收明确授权处理的论文提取文本。出版信息查询使用 Crossref；普通阅读不需要这些外部服务。
- 模型名称、价格和上限属于可变配置，当前后端价格不是官方账单的替代品，变更时应重新核对。
- PDF、元数据和旧笔记是待分析资料，不是可执行指令。复杂分栏、扫描文字及图表需要额外核对。

发布前请检查 `git diff --cached` 和待上传文件列表，不要强制加入 `.gitignore` 中的个人文件。项目当前未附开源许可证；不要把第三方论文或依赖的许可视为本项目自行授予。
